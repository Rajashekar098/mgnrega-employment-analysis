# MGNREGA Telangana Aadhaar Seeding Status Analysis

## Project Overview
This project visualizes and analyzes public policy data from the Mahatma Gandhi National Rural Employment Guarantee Act (MGNREGA) in the state of Telangana. The analysis specifically focuses on the Aadhaar seeding status of workers, a critical metric for tracking transparency, authentication, and the efficiency of Direct Benefit Transfers (DBT) in rural employment.

## Technology Stack
* **Data Processing:** Microsoft Excel
* **Business Intelligence & Visualization:** Tableau Public

## Key Metrics Analyzed
* **Aadhaar Seeding Rates:** Tracking the percentage of active rural workers whose job cards are successfully linked and authenticated with Aadhaar.
* **Regional Implementation:** Comparing seeding success rates and employment generation across different districts in Telangana.
* **Resource Allocation:** Evaluating the efficiency of rural job card utilization and workforce distribution.

## Files in this Repository
* `MGNREGA Telangana Aadhaar Seeding Status.xlsx`: The foundational dataset detailing Aadhaar integration and employment metrics for the region.
